# 行动序列卡片优化与验收

日期：2026-10-11。修改位于 HSR-Database 的 `develop`，保留角色选择器阶段的未提交改动。本轮仅优化行动序列展示，没有修改引擎、角色编队交互或 Inspector 布局及表单。

## 组件与信息层级

- 新增 `src/lib/components/action-planner/ActionCard.svelte`，未来记录、当前队列与战斗开始共享卡片组件。普通卡片主区域最小高度 76px，卡片间距 8px，头像 48px、小圆角，复用 `getCharacterIconUrl()` 与 `AssetImage` 缺图 fallback。移除了圆形头像、可见序号与旧连续行样式。
- 角色名称为主文字，行动次数与有效 SPD 为辅助文字。未来记录以累计 AV 为主数值，始终显示 `+推进 AV`；当前队列显示剩余 AV及标签，没有累计或推进 AV 字段。数值仍按 locale 格式化为最多三位小数，原始数据和计算精度不变。
- 无配置操作时不显示效果摘要。同类操作显示名称及数量，混合类型只显示总数量；添加与解除速度效果合并为“速度变化”。摘要统计已配置操作，包括目标缺失等未执行操作，不影响执行顺序。
- 当前队列的 Buff 明细继续可展开，独立标记为“速度状态”，显示数值、持续回合和实例 ID。展开控件与主卡片按钮并列，避免按钮中嵌套交互元素。
- 战斗开始使用较矮的系统卡片，无头像，保留金色图标、AV及非空摘要。新增五组成对中英文站点消息，调用均传入显式 locale。

## 展示接口与交互

`src/lib/action-planner/presentation.ts` 定义展示专用的 `ActionCardData` 判别联合，分别保留未来记录的累计/推进 AV、当前队列的剩余 AV/Buff，以及系统事件 AV。`futureActionCard()`、`queueActionCard()` 只投影现有结果；`summarizeEffects()` 只归类操作，不排序、不验证或过滤操作，不依赖角色数据或消息文本。

卡片使用原生按钮与 `aria-pressed`，支持鼠标、Tab、Enter、Space、Hover 和 Focus。未来记录继续关联原来的单位 ID 与行动次数。当前队列点击选择 `entry.unitId + entry.turn` 对应的下一次自然行动；超出预算时可配置该锚点，沿用“无法触发”机制，不生成虚假的回合前预览。队列步进保持原有行为，编辑和重算后保留稳定选中锚点。

两种视图保留原始数值测试属性。卡片使用现有 tokens，窄栏通过容器查询换行，头像保持方形，AV 不截断；列表保持桌面 48rem、移动端 32rem 的最大滚动高度。

最终确认两个上游仓库工作区均为空，与开始时一致；引擎和 Inspector 源文件没有本轮修改。未提交、推送或远程部署。

## 使用与限制

本地预览：`http://127.0.0.1:4173/game-tools/action-planner/`；英文使用 `/en/game-tools/action-planner/`。添加角色后可直接选择行动卡片编辑事件，或切换当前队列、步进并展开速度状态。

当前仍为单波次，因此没有波次开始节点。未执行全站回归、Firefox/Safari 或远程环境检查；可人工复核这些浏览器的容器查询、键盘焦点和不同缩放比例下的排版。主卡片最小高度适用于常规内容，长名称、多行摘要、窄栏或展开 Buff 时允许增高。
