## Executive Summary

**建议下一轮以 N=1 作为普通「遗器评分」的候选正式语义，K 保持 65,536，暂时保留直接生成的 257 点表示。当前证据足以启动经维护者批准的迁移工程，但不足以宣称 N=1 全量产物已经通过发布门禁。生产在批准和全量验证完成前继续保持 N=3。**

- 当前 N=3 实现正确：同部位、同主词条，三件自然五星遗器全部强化到 +15，以 Raw Substat Utility 取最优。N=1 衡量单件条件质量，N=2/3 衡量有限样本择优质量；选 N 是产品目标选择，不是修复一个采样错误。
- 精确 CDF 满足 `F_N(x)=F_1(x)^N`，离散重复值不破坏该关系。实验按正式 N=3 查询 P₃，再计算 P₁=P₃^(1/3)、P₂=P₃^(2/3)，不改变 α、主适配度、主完成度、六槽权重或 Set Integrity。
- 121 件真实可评分遗器的平均分为 87.89 / 81.87 / 77.42（N=1/2/3）；32,640 件分层合成遗器为 46.94 / 34.01 / 27.73。自然随机 +15 子集在 N=1 下只有 3.33% 达到 95 分，未显示「一般遗器大面积成为极品」；真实已养成样本的高分拥挤则确实明显。
- 未找到截图同款长夜月能量绳：本地两条 1413 绳子都是 HP 主词条。依据当前展示截断规则和合法 affix 档位，可以推定一组与截图一致的数值，得分 **76.96 / 64.88 / 55.78**，复现约 55.8 的显示。它不是原始 Enka 记录复算。该绳主适配度只有 0.8；攻击%、效果命中副权重均为零，这也解释了视觉直觉与分数的差距。
- 六条件独立模拟显示：从压缩 N=3 开立方，N=1 的最大 CDF 误差为 0.03075–0.05978，低尾部明显失真；直接模拟 N=1 的 257 点表示误差为 0.00167–0.00377。**不能把重映射分位数包装为正式 N=1 Benchmark。**
- K 加倍确实降低独立重复的差异，但不消除压缩误差，也不能恢复 N=3 低尾部丢失的信息。N 改变通常带来十几至几十评分点的变化，远大于当前直接 N=1 的数值不稳定；不建议先用增加 K 来解决评分语义问题。

### 条件与独立性

正式核心对每个条件重置一次 `createSeededRng(123456789)`。一轮调用 `generateFarmingExperiment(slot, farmingBudget(3), model, rng, item.mainStatKey)`，三次自然生成均接收同一 `slot` 和固定 `mainStatKey`。固定主词条直接选对应项，不执行主词条随机抽取或拒绝采样；因此没有把主词条出现率混进副分布。

每次 `generateNaturalRelic()` 都新建 `available`、`substats` 和计数状态，使用 PRNG 的后续随机数，前一件选过的副词条不会从下一件池里消失。三件生成完后才逐件算 U、取最大，随后排序全部 K 轮结果。没有共享强化状态或复用同一件样本的问题。

“独立同分布”是该伪随机模拟模型的设计前提：相同规则、独立状态、连续随机流；有限状态的确定性 Mulberry32 不能构成严格概率独立性的数学证明。不同条件重置同 seed 还会形成共同随机数相关性，所以 2,744 条分布也不能当成 2,744 次独立统计重复。本轮交叉验证按条件和 N 使用不同 seed，不把相同 seed 的确定性复算当作独立验证。

N 的唯一直接变化是最终随机变量 `max(U₁,…,U_N)` 的分布；U 公式、主项、Effective Hits 和 Set Integrity 不变。采样消耗量也随 N 改变，因此同 seed、不同 N 的结果不能假设为逐轮一一配对。

### CDF 查询的边界

`exactEmpiricalCdf()` 计算 `#{U≤x}/K`。`lookupDenseCdf()` 对相同 knot 找到最后一个 `≤x` 的位置，用最右点的分位级别；因此右连续，不采用 mid-rank。单独一个最小 knot 在值等于它时返回 0，而精确经验 CDF 至少为 1/K；最大 knot 及其上方为 1。重复最小值可产生大于零的跳跃，但跳跃质量仍被 1/256 网格近似。

257 点不是完整离散阶梯 CDF，也不是逐个 U 的 exact rank。当前 0.005 gate 校验的是对**生成样本**的表示误差，不是对未知真实总体 CDF 的总误差保证。

## Mathematical Analysis

### 顺序统计量与实验评分

令同条件独立 Uᵢ 的右连续 CDF 为 F₁，则：

`P(max(U₁,…,U_N)≤x) = P(U₁≤x,…,U_N≤x) = ∏F₁(x) = F₁(x)^N`。

这个等式在离散分布、重复值、零效用质量点处同样成立。由精确 F₃ 可唯一恢复 F₁=F₃^(1/3)、F₂=F₃^(2/3)。正式 N=3 分布查询得到的则是近似 P̃₃，本轮所有比较表使用它的理论重映射：

- 普通槽：`S_N = 100 × (0.35 × a × Q + 0.65 × P̃₃^(N/3))`。
- HEAD/HAND、1506 NECK/OBJECT：`S_N = 100 × P̃₃^(N/3)`。
- 完整配装：`B_N = 0.95 × Σ(slotWeight × S_N) + 5 × SetIntegrity`。

对缺件配装只保留可评分单件，Build 继续 unavailable。实验的 N=3 单件和 Build 必须与正式 scorer 一致，脚本逐例断言，未借缺件重归一化抬分。

| 精确单件条件百分位 F₁ | N=1 副评分 | N=2 副评分 | N=3 副评分 | 最优主词条普通槽 N=1 / 2 / 3（Q=1） |
| --- | ---: | ---: | ---: | --- |
| 0.10 | 10.00 | 1.00 | 0.10 | 41.50 / 35.65 / 35.07 |
| 0.50 | 50.00 | 25.00 | 12.50 | 67.50 / 51.25 / 43.13 |
| 0.75 | 75.00 | 56.25 | 42.19 | 83.75 / 71.56 / 62.42 |

### 排名与分辨率

P₃→P_N 对 [0,1] 严格单调，但实际 U→压缩 CDF 是非递减的。相同角色、部位、主词条且主完成度相同，最终分数不应发生严格排序反转；原有重复值和截断平局仍是平局。若同主词条但等级/完成度不同，主项已经不同，不能再保证最终排序不变。

不同主词条之间 a、主副同 key 排除产生的条件 CDF 都可能不同，非线性变换会改变主副补偿关系；不同配装中多个百分位经非线性变换再加权，Build 排名也可能改变。纯副词条百分位排名保持，不等于最终跨主词条或跨 Build 排名保持。

连续近似下，随机单件 F₁(U) 均匀，因此纯副评分均值约为 `100/(N+1)`，即 50 / 33.33 / 25；中位数为 50 / 25 / 12.5。这正是 N=3 的系统性压分机制。离散右连续 F₁(U) 并非严格均匀，均值会受 ties、数值精度与压缩影响。

### 为什么重映射不能成为正式产物

若原 CDF 误差为 ε，开立方的局部误差约为 `ε/(3P₃^(2/3))`，在低尾部放大；一般只有 `|a^(1/3)-b^(1/3)|≤|a-b|^(1/3)` 这样的宽松界。原 0.005 gate 不能推出重映射仍满足 0.005。

N=3 网格第一步 1/256 对应 N=1 百分位约 0.15749。N=1 的 10% 位置对应 F₃=0.001，小于第一格：即使中高段很好，底部约 15% 也由很少 knot 控制。正式 N=3 的样本最小值下面，P̃₃ 已截为 0，开根仍是 0；丢失的低尾部不能靠代数恢复。最大值上方同理保持 1，不能恢复极端上尾分辨率。

另外，有限 K 的经验 F̂₃ 开根并不等于另一次单件实验的 F̂₁；有限样本和非线性变换的差异不说明总体公式错误。离散 ties 的公式本身无偏差来源，主要风险是压缩跳跃、端点和有限采样。不能通过把 quantile 值开根生成 U 分位表：开根的是 CDF 概率，U 的单位和排序不变。

## Synthetic Sample Comparison

## Monte Carlo Cross-Validation

### 设计与误差口径

六条件分别覆盖长夜月能量绳/固定头、1102 固定手、1001 速度脚、1506 agnostic 能量绳、1205 治疗衣。每条件独立 N=1/2/3 各 K=65,536，全部调用现有真实遗器生成器。另按正式 seed 再生该条件 N=3，确认其压缩 knots 与正式产物一致。没有使用人工随机 U 分布。

条件序号 i 从零开始：独立 N 的 seed 为 `20261011 + 100i + 10N`。K 调查使用两条独立单件流，seed 为 `20262011 + 100i` 和 `20272011 + 100i`；每条生成 131,072 件，再取前 65,536 件比较。两个 K 之间是嵌套样本；同 K 的两条流独立，不假装四次独立试验。

完整 MC 共生成 5,111,808 件，仅在内存保存 Utility 数组：每条件正式复算 3K、独立三 N 共 6K、双重复单件共 4K，六条件合计 78K。脚本最终运行约 14.7 秒；含匿名/合成统计处理，不是全量生产成本测速。

比较网格包含各样本的 U 取值、相邻值中点、各取值略左点和外侧端点，补充检测离散跳跃与截断。左点按浮点尺度减 4ε，少数近邻浮点值可能合并/跨越；不等于对实数轴给出解析 sup 证明。区域按独立 N=1 经验百分位划分。最大/均值误差为这些查询点上的绝对 CDF 差；均值对查询点等权，不是玩家遗器分布加权误差。直接表示误差另用未修改的 `measureQuantileError()`。

K 加倍在本轮全部六条件降低了重复经验 CDF 的 max/mean；但只有两条流，不足以精确估计跨 seed 的长期平均改善比例。表示误差并不随 K 单调下降：例如 1506 的 257 点最大误差反而略升。513 点对 1413 HEAD 改善接近一半，对 1001 FOOT/1205 BODY 则很小，说明不能一概认为采样或表示哪一项永远主导。

重复 U 的精确浮点取值占比在第一条 65k 流为 15.31–47.76%，最大单点质量为 0.000137–0.001465；六条件未采到 U=0 的质量点。重复率高不等于单个 atom 很大：很多小 atom 和近邻浮点值聚集也会形成插值误差。右连续查询保留右侧质量，误差更容易集中于跳跃附近和端点。按精确 `number` 相等统计，未额外把数学上近似相等的 U 合并；不宣称消除了浮点细碎差异。

**精度建议：先保持 K=65,536 / 257 点，直接生成 N=1 并逐条 gate。** 若将来要求纯副评分表示误差≤0.2 分，现有部分 257 点条件不满足，再研究 513 点或离散 atom 表示；若要求总体统计不确定性更小，再增加 K。两者不能互相替代。没有明确收益目标，本轮不继续扩大 K。

## Product Interpretation

### 评分目标的选择

| 选择 | 可向用户解释的条件副语义 | 优点 | 代价 |
| --- | --- | --- | --- |
| N=1 | 同角色、部位、主词条的一件自然随机五星 +15，U 不超过当前件的概率 | “单件质量”直观；中间品质有可读分数；条件 percentile 解释简单 | 已养成遗器在高分区更拥挤；需要重审极品等级措辞 |
| N=2 | 两件同条件遗器都强化，当前 U 超过其最优值的条件概率 | 中等压分；高段比 N=1 更展开 | 仍需要解释为什么选择两件；没有自然的真实刷取成本对应 |
| N=3 | 三件同条件都强化后的最优值基准 | 高分更挑剔、极品分辨率更好；保留已批准政策 | 单件 50% 品质纯副分只有 12.5，普通用户很难直觉解读；中等实用品被明显压低 |

N=2 有明确的两件择优数学语义；只有产品明确需要该目标时才有独立价值。仅因为分数处于 N=1 与 N=3 之间，不足以成为默认政策理由。

N=1 高段分辨率确实下降：纯副 F₁ 从 0.95 到 0.99，N=1 差 4 分，N=3 差约 11.29 分；所有纯副 95 分的入场要求，分别对应单件 F₁≥0.95、√0.95≈0.97468、³√0.95≈0.98305。固定/agnostic 的等级可据这个关系重新校准，普通槽和 Build 必须因主项与汇总另行审议，不能整套等级阈值直接开根。

真实样本中 N=1 的 95–100 达到 52.07%，值得维护者认真考虑成熟玩家高段展示；自然随机样本同档只有 3.33%。这两项应同时看：N=1 没有把大量一般遗器变成 95 分，但对成熟样本确实可能需要更细的极品等级或 percentile 辅助说明。本轮没有添加这些 UI。

对普通“遗器评分”，建议以单件条件质量为基准；N=3 更适合明确标注的条件择优基准。即使选 N=1，主副加权后的最终分数仍应解释为质量合成分，而不是完整遗器的总体百分位。高分也不证明该角色实际战斗提升大小。

### 刷取成本边界

固定主词条的 N 件样本**不等于刷 N 次副本**：未计指定部位/主词条出现率、一次掉落件数、强化筛选与费用、定向合成、保留策略或体力。N=1/2/3 都不能作为完整刷取难度/体力成本估计。

未来可以区分“单件质量”与“获得成本/难度”两个概念；当前只有条件质量与条件择优参照，后者不能直接命名为真实刷取成本。本轮不建立体力模型，也不因能量主词条稀有额外加分。

| 审计与门禁 | 发布实际新 bytes/hash、N/K/seed/source provenance、逐条件表示误差与汇总；不伪造新 generation audit、不放宽失败门槛 |
| 全量产物 | 2,744 个条件全部直接重新模拟、编码、验证；本轮六条件与重映射不能替代它 |
| Runtime Loader / Manifest | 更新新产物及审计绑定 hash；让 expected config、生成端、消费端同时指向 N=1；确认旧 N=3 元数据/身份被拒绝，缓存随绑定失效 |
| 相关测试 | 更新明确 N=3 的 fixture/metadata 断言；保留 stale identity 拒绝、ties、数值界限、覆盖、表示 gate、确定性与 loader hash 测试；检查真实评分 DTO 数值行为 |
| 文档与维护命令 | 更新数学契约、Benchmark 维护、用户说明、生成/验证/确定性复算口径；原命令可沿用，必须标注新产物身份 |

不需要改变：主副权重/Profile 审核政策、Flat 4/9、主词条归一化、α=0.35、Effective Hits、Set Integrity、六槽权重、单件和 Build 合成公式、合法自然生成规则、canonical decode/normalization、DTO 结构。只有 N 变化且 quantile 表示保持时，`lookupDenseCdf()` 也可不改。Profile provenance 仍需绑定当前锁定输入，但无证据要求为 N 变化重新人工审核权重。

现有全量 N=3 生成审计为 1,283.20 秒、约 21.39 分钟；同 K 改 N=1 时遗器生成次数从 539,492,352 降至 179,830,784，采样主体成本约三分之一。按历史耗时机械线性折算约 428 秒，仅为估算：排序、编码、identity 和 gate 不按 N 缩减，硬件/进程负载也不同，不能承诺总耗时。若 N=1 同时 K 加倍，则生成次数是旧正式工作的三分之二，单条件排序和误差查询也更贵。

K 增加不增加 quantile 数量，正式分布文件仍在原来的大小量级，数值文本长度和审计字段会略变；内存/时间随样本数增加。257→513 则每条件 knot 数近乎翻倍，主体产物与加载成本增加，现有类型及消费 gate 不能直接接受。N、K、points 任一变化都影响 sampling identity，禁止复用旧审计或混用语义。

建议保留现有 N=3 文件的 Git 历史与本报告的 bytes/hash 作为历史基线；若要额外存档，使用明确独立的历史位置和标签，不进入活动 loader、不把两套大产物同时默认打包。未来正式生成应继续采用 staging、全量 gate 后发布；本轮没有清理或覆盖正式文件。

## Recommendation

1. **目标建议：N=1。** 核心理由是默认评分应表达“单件条件质量”，不是均值更高。N=3 对中等实用品压分，N=2 没有独立的默认产品理由；若维护者决定评分目标就是严格择优，保留 N=3 同样数学正确，但应明确解释该语义。
2. **K 建议：65,536。** 六条件重复数值稳定性足以支撑当前显示与政策判断；131,072 有测得的改善，但成本收益不足以成为此次迁移前置要求。不能承诺每件评分最后一位永远稳定。
3. **表示建议：保留直接 N=1 的 257 点与 0.005 gate。** 本轮全部 30 个直接 N=1 样本表示通过。六条件不是全量保证；未来任何条件失败应先诊断 ties/端点/表示，而不是暗中切 513 或放宽门槛。
4. **批准后可以启动迁移工程。** 必须全量直接生成 N=1、发布新 identity/audit/Manifest 绑定并验证旧身份拒绝，才可变更正式语义；当前重映射只用于研究。没有必要先扩大 Monte Carlo 来决定默认目标。
5. **剩余研究限于具体验收目标。** 若要求更细极品分辨率，先决定等级/文案和期望误差，再研究 513 点、atom 表示或统计精度；真实玩家样本更大也只能帮助验证阅读体验，不能推翻顺序统计关系。本轮不追加网络样本或 α 搜索。

仍需维护者决策：

- 默认“遗器评分”究竟承诺单件质量还是有限择优质量；是否批准 N=1 正式迁移。
- N=1 下成熟玩家高分拥挤是否通过等级/文案处理，是否需要单独保留条件择优参照。
- 是否需要可见 Benchmark 政策版本，以及 N=3 历史产物的保存方式。
- 数值精度目标是现有 0.005 表示门槛，还是更严格的总误差/极品区分要求；它决定是否增加 K 或点数。
